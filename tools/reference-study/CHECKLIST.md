**参考视频深入拆解 · 分类核查清单 v1**

与本目录README和数据模板配套。各项是否适用、证据范围及未决项由研究者记录，不预设某条视频已完成核查。

本清单由 Codex 使用。每条核查的结果连接具体时间、语义步骤、元素或动作，不只打一个完成勾。状态使用“待查／已核实／有歧义／未观察到／不适用”，后两项写明检查范围或理由。观察结果、作用推断与试验结果分别保存。一个元素允许承担多种作用，也可能随时间改变作用。

**01 · 原片、证据和观看条件**

- [ ] 01.01 固定源文件、版本、校验值、总时长、尺寸、帧率或时间戳规则、音轨信息。
- [ ] 01.02 区分作者画面、视频内字幕、平台水印与截图时叠加的播放器控件。
- [ ] 01.03 记录源语言、字幕语言、翻译来源；原语音、源字幕和译述各有独立字段。
- [ ] 01.04 原片正常速度连贯观看；记录实际覆盖范围，不以抽帧浏览代替。
- [ ] 01.05 原声音轨实际核对；转写成功不等于语气、重音、音效和配乐已听辨。
- [ ] 01.06 用全片索引找位置；变化和交接回到原帧率；静止、循环和无口播区也进入覆盖表。
- [ ] 01.07 压缩噪声、重采样、播放器缩放与真实设计变化分别判断。
- [ ] 01.08 标明证据来自原片、研究标注图、重建或试验副本，避免互相替代。

**02 · 全片的表达目标和叙述顺序**

- [ ] 02.01 面向谁、需要什么前置知识、希望观众最终理解或做什么。
- [ ] 02.02 开头先建立的问题、冲突、承诺、身份或好奇是什么。
- [ ] 02.03 全片依次回答哪些问题；每一段为什么放在这个位置。
- [ ] 02.04 哪些信息是后文前提；哪些概念先介绍、后深化或纠正。
- [ ] 02.05 举例、解释机制、对比、回应顾虑、限定与行动建议各承担什么责任。
- [ ] 02.06 哪些信息刻意延后揭示；哪些已经提前埋入画面。
- [ ] 02.07 哪些句子可以合并在同一事件中，哪些需要真正切换理解任务。
- [ ] 02.08 感受和语气在哪里变化：轻松、强调、谨慎、期待、确定或回到观众。
- [ ] 02.09 首尾有哪些词、形状、动作或问题的呼应；回访时多了什么新含义。
- [ ] 02.10 原片是否有论述跳跃、信息多余或画面支持不足，不能只记录优点。

**03 · 每句文案及句内逻辑**

- [ ] 03.01 校对原话与中文句意，专名、否定、条件、程度、数量和范围单独核对。
- [ ] 03.02 按意义划出“前提、动作、对象、条件、结果、例子、限制”，不只按字幕换行切句。
- [ ] 03.03 当前语义步骤前，观众应该已经知道什么；之后应多理解什么。
- [ ] 03.04 关键动词究竟是执行、等待、归类、筛选、比较、批准、停止还是其他关系。
- [ ] 03.05 并列、先后、因果、包含、互斥、归属、条件分别是什么，避免互相画错。
- [ ] 03.06 “它、这个、后来”等指代对应哪个持续存在的画面对象。
- [ ] 03.07 抽象说法如何被具体例子补全；画面是否引入原话没有的断言。
- [ ] 03.08 一句中哪里才出现结论，哪里只是铺垫；早出文字是否破坏揭示顺序。
- [ ] 03.09 口语中的重复、停顿或转折有何表达作用，画面怎样回应。

**04 · 口播、字幕、标题与图形的分工**

- [ ] 04.01 分别记录口播、底部字幕、主标题、框内文字、图示说了什么。
- [ ] 04.02 声画是在复述、概括、举例、补充、限定、演过程，还是有意形成反差。
- [ ] 04.03 画面是否给出独立解释，还是把旁白又拆成几个大字。
- [ ] 04.04 哪些内容必须听、哪些必须读、哪些可以直接看变化理解。
- [ ] 04.05 同时出现两处文字时，第一阅读目标和第二阅读目标是否清楚。
- [ ] 04.06 画面相对语音是提前、同步还是延后；起效的是关键词、整句含义、停顿还是动作结果。
- [ ] 04.07 句子跨画面、画面跨句子时，旧信息怎样保持可辨认。
- [ ] 04.08 图形、数字或大字是否掩盖较小的条件；大小关系是否误导结论。
- [ ] 04.09 静音看、只听音频和完整声画各缺什么；测试结果只说明实际观察到的分工。

**05 · 视觉对象与表现形式的选择**

- [ ] 05.01 这段为何选择具体物件、界面、角色、图表、过程图、大字、实拍或其他载体。
- [ ] 05.02 观众凭什么认出它；哪些特征是识别所必需，哪些只是风格细节。
- [ ] 05.03 现实物件与抽象概念怎样对应；隐喻是否会带来错误理解。
- [ ] 05.04 真实产品页、示意界面、重建界面与抽象图解分别承担什么，是否清楚区分。
- [ ] 05.05 同一事情能用什么合理的其他载体讲；当前选择在哪方面更合适。
- [ ] 05.06 抽象程度是否适当；具体细节是否足够，是否又挤掉主要关系。
- [ ] 05.07 该对象是否有可演示的状态，形式是否支持这段真正的动词。
- [ ] 05.08 同一对象的持续身份如何保持；对象变成另一个对象时有什么可见依据。
- [ ] 05.09 哪些造型承担性格、亲近感、触感或趣味；不把这些一律当无用装饰。

**06 · 整体布局与空间中的关系**

- [ ] 06.01 记录画面各区域的实际边界、占比、主轴、对齐线、安全区与视觉重心。
- [ ] 06.02 第一眼、第二眼和下一步预期看哪里；用什么大小、反差、位置和动作支持。
- [ ] 06.03 主体与辅助的区别来自什么职责，不能只按面积判断。
- [ ] 06.04 左右、上下、并排、包围、分隔、连接分别表达什么关系。
- [ ] 06.05 外框之间、框与标题、框与字幕、框内对象之间的边距和间距如何配合。
- [ ] 06.06 空间为何等分或不等分；某块更大、更亮或更靠近是否有内容理由。
- [ ] 06.07 留白是在突出主体、留阅读空间、预留后续内容，还是尚未设计的空缺。
- [ ] 06.08 随时间推进布局怎样改变；新增内容如何接入；旧内容是否被挤、缩、淡或移走。
- [ ] 06.09 被遮挡、裁切、贴边、出框和层叠如何形成关系或动势。
- [ ] 06.10 视觉放大来自对象缩放、局部揭示还是整个视角变化；可见结果与实现推断分开。
- [ ] 06.11 手机页等纵向素材如何进入横幅整体；周围元素是否与它实际互动。
- [ ] 06.12 在正常观看尺寸检查字和关键细节，不仅在放大截图中判断版式。

**07 · 每一个元素及子部件的完整登记**

- [ ] 07.01 建立场景→容器→子对象→细部的元素树；同一元素跨段沿用身份。
- [ ] 07.02 登记背景底色、纹理、点阵、分区底板、窗口外壳、内框与内容区。
- [ ] 07.03 登记标题、数字、正文、标签、脚注、品牌、状态字及所有非字幕文字，保存准确内容。
- [ ] 07.04 登记图标本体、图标底盘、角色脸与表情、标记、徽章、光标、按钮及选择器。
- [ ] 07.05 登记连接线、箭头、虚线区域、分隔线、下划线、光圈、扫描线与强调描边。
- [ ] 07.06 进度控件拆出底轨、填充、端点、数字、刻度、状态字及其他真实可见部件。
- [ ] 07.07 日历、时钟、纸页、票券等拆到具体组成：格子、日期圈、刻度、指示点、页内内容等。
- [ ] 07.08 不同填色、阴影、发光或纹理层记录为对象的外观属性；独立变化的层另有记录。
- [ ] 07.09 重复对象登记数量或不确定性、实例分布和变化规律；特殊成员单列。
- [ ] 07.10 检查先出现后消失、只有几帧、遮挡后露出及转场过程中才出现的元素。
- [ ] 07.11 逐元素记录可见开始、稳定、状态变化、退出、回访与职责变化。
- [ ] 07.12 清单→画面逐项定位，画面→清单逐区域反查；入场、中段、终态、交接都检查。

**08 · 元素为什么这样画、这样放**

- [ ] 08.01 对每个元素说明“它具体是什么”，禁止只写“装饰、卡片、信息”作为全部解释。
- [ ] 08.02 说明形状、长宽比、大小、方向、圆角、线宽和实虚边界为什么可能适合它。
- [ ] 08.03 说明位置、对齐、包含、距离与层次如何支持当前关系。
- [ ] 08.04 说明颜色是识别、分类、状态、强调、性格还是美术呼应；不能默认全片一种颜色只对应一个意思。
- [ ] 08.05 说明图标为何使用该符号，需要多少细节才能辨认，是否有文字补充。
- [ ] 08.06 区分具体描绘、界面惯例、视觉隐喻、品牌母题与局部审美取舍。
- [ ] 08.07 识别一物多用：例如既是容器也是操作入口，既是身份也是转场连接。
- [ ] 08.08 删除或更换该元素会损失什么：含义、边界、阅读顺序、连续性、反馈、美感或性格。
- [ ] 08.09 对有歧义的造型保留替代解释，不能从漂亮直接倒推出唯一导演意图。
- [ ] 08.10 记录可以跨内容复用的原则与需要重做的具体造型，保留原片特定语境。

**09 · 字体、字形与排字**

- [ ] 09.01 区分可确认字体与视觉近似；字体名未知时记录实际字形特征。
- [ ] 09.02 比较实际墨量、字面宽窄、笔画形态、转角和视觉重量，不能只记字号与字重数字。
- [ ] 09.03 标题、核心数字、结论、标签、状态、字幕与脚注各自的字级和职责。
- [ ] 09.04 行距、字距、基线、断行、对齐与容器宽度如何配合。
- [ ] 09.05 文字是否作为形状参与构图，是否与开关、图标、路径或遮罩组成一个对象。
- [ ] 09.06 彩色强调、下划线、反白、描边分别强调哪个语义单位。
- [ ] 09.07 字幕的切句、位置、行长、换页和强调与口播是否一致。
- [ ] 09.08 数字滚动、逐字出现、文字替换时是否影响辨认、读序和重心。
- [ ] 09.09 日文、中文、英文、数字混排的字面差异；移植到中文时哪些比例必须重排。
- [ ] 09.10 真实显示尺寸下检查可读性；需要停下来放大才可读的内容是否真是主要信息。

**10 · 色彩、形状、材质和精致感**

- [ ] 10.01 全局颜色与每段局部颜色分别承担什么；大面积色与小面积强调怎样配比。
- [ ] 10.02 明暗切换与内容章节、情境或注意力有没有关系。
- [ ] 10.03 同一颜色在不同对象、不同状态中是否改变职责。
- [ ] 10.04 形状家族怎样呼应：圆、胶囊、圆角矩形、线条与文字之间的比例和差异。
- [ ] 10.05 外框与内框的圆角、线宽、填色和边界是否形成清楚层级。
- [ ] 10.06 阴影、发光、反射、渐变的方向、软硬、范围和使用位置；哪些地方刻意保持平。
- [ ] 10.07 细线、刻度、端点、图标粗细、内边距与微小偏移怎样让对象显得完整。
- [ ] 10.08 点阵或纹理的尺寸、疏密、对比与持续变化；它是否抢主要信息。
- [ ] 10.09 对称与不对称、几何与有机、严肃与活泼如何共同形成气质。
- [ ] 10.10 从压缩视频得到的颜色和尺寸标为近似测量，不冒充作者源文件参数。

**11 · 每一项运动本身**

- [ ] 11.01 记录运动对象、触发、起止时间／帧、初态、过程、终态和证据窗口。
- [ ] 11.02 检查位移、缩放、旋转、透明度、颜色、描边、遮罩、裁切、形态和内容替换。
- [ ] 11.03 数字、进度、图标、勾叉、标签、模式等状态变化逐项登记，即使对象没有移动。
- [ ] 11.04 路径、方向、距离、轴心和幅度为什么适合对象与当前含义。
- [ ] 11.05 启动、加速、减速、回弹、超出后回位、停顿及收尾怎样形成动作性格。
- [ ] 11.06 是否存在预备动作、后续跟随、部件错峰、弹性或拖尾；有则定位具体过程。
- [ ] 11.07 循环运动的周期、相位、幅度、启动与停止；多实例是否一致或交错。
- [ ] 11.08 角色眨眼、轻动、波形、靶心、状态点等持续活动各承担什么，是否争抢注意力。
- [ ] 11.09 “停止运动”是否为重要结果，冻结的是哪部分，其他部分是否继续反馈。
- [ ] 11.10 相同动作在不同对象中是否有不同作用；不把全部运动归成“增强节奏”。
- [ ] 11.11 区分可观察的运动曲线与原始软件、算法或图层的猜测。

**12 · 框内编排、联动与注意力交接**

- [ ] 12.01 一个框内的内容从空或初态到完整，具体经历哪些有含义的步骤。
- [ ] 12.02 一个触发影响哪些子部件；标签、内容、状态、角色和反馈是否成组更新。
- [ ] 12.03 同时动的对象有哪些，哪个应成为主角，哪些只保持低强度运行。
- [ ] 12.04 主动作发生时，其他对象怎样变淡、停止、缩小或维持稳定。
- [ ] 12.05 前一步结束与后一步开始是否重叠，重叠帮助衔接还是影响辨认。
- [ ] 12.06 旧对象保留多久，保留的是参照、前提、结果、导航还是情绪余韵。
- [ ] 12.07 哪些变化需要让观众看见过程，哪些可以直接替换而不损失关系。
- [ ] 12.08 完整结果能读多久；阅读与次要运动、下一项进入如何配合。
- [ ] 12.09 视线交接由颜色、位置、方向、遮挡、光标、声音或语义中的哪几项协同支持。
- [ ] 12.10 注意力路线写为画面设计支持的推断；没有眼动测试时不声称测得真实视线。

**13 · 节奏、停留和理解速度**

- [ ] 13.01 分开观察全片章节、同场语义步骤、单次动作、持续小运动四个尺度。
- [ ] 13.02 记录每次实质新增的含义；画面在动但含义未推进的情况单列分析。
- [ ] 13.03 对照语速、语义密度、画内文字量、动作强弱和结果阅读时间。
- [ ] 13.04 大字、细节、整体、局部等观看尺度怎样变化，什么时候需要恢复整体关系。
- [ ] 13.05 密集段和集中段怎样分配，哪里需要吸收结果、比较或等待情绪落下。
- [ ] 13.06 停留分别是阅读、对照、悬念、强调、表示停止，还是无理由等待。
- [ ] 13.07 下一步是否被机械绑定到某个词而出现晚；提前铺场是否可以使关系更自然。
- [ ] 13.08 快的感觉来自信息推进、动作重叠、短动作、声音、频繁切换中的哪些组合。
- [ ] 13.09 相邻段落长短和动作强度是否雷同，是否有内容上的原因。
- [ ] 13.10 统计只服务定位，不制定全片统一的静止上限、每秒事件数或布局数量。

**14 · 场内变换、场间转场与章节连接**

- [ ] 14.01 建立所有视觉交接清单，包括同场换态、扩展布局、主次切换与完整换场。
- [ ] 14.02 每次交接前，上一件事完成到哪里；下一件事为什么此刻接入。
- [ ] 14.03 前一终态→退出／保持→过渡→后一初态→新阅读重点全程留证。
- [ ] 14.04 保留或传递了哪些对象、位置、形状、颜色、方向、文字或语义。
- [ ] 14.05 哪些元素退出，哪些提前进入，哪些变形或换身份；是否真能看出同一对象延续。
- [ ] 14.06 转场使用硬切、淡化、遮挡、扩张、擦除、移动、变形或其他方式，为什么可能适合这里。
- [ ] 14.07 转场如何利用原有元素；是否引入专用形状，是否具有品牌或情绪职责。
- [ ] 14.08 完全遮住、最少信息、前后重叠等关键状态及持续时间分别是什么。
- [ ] 14.09 空白、黑帧、切点和转场后的落稳是否有意；字幕与声音是否跨越边界。
- [ ] 14.10 原片的分析分段不等于实际剪切边界；时间点须回到连续原片核对。
- [ ] 14.11 同类转场何时重复、何时变化，是否有解释层级或情绪上的理由。

**15 · 语音、音乐、音效和静默**

- [ ] 15.01 核对实际口播开始、结束、句内停顿、衔接和未识别区间。
- [ ] 15.02 重音、语气、语速变化与情绪落点分别落在哪些语义单位。
- [ ] 15.03 语音停顿与画面阅读、变化、揭示或转场怎样对应。
- [ ] 15.04 区分BGM、实际音效、素材原声和语音，不从光标动作猜一定存在点击声。
- [ ] 15.05 音效属于提示、反馈、动作触感、转场或强调；声响与视觉触点是否一致。
- [ ] 15.06 音乐何时进入、离开、变化或让位；是否与章节和情绪相关。
- [ ] 15.07 节拍与动作是否确有对应；未测量时不编造BPM或“所有动作卡点”。
- [ ] 15.08 声音跨场提前或延续时怎样帮助连接，静默是否承担强调。
- [ ] 15.09 观察声音层级和整体听感，客观音量测量与主观听感分开记录。
- [ ] 15.10 单条混合音轨难以分辨的声音标为有歧义，不能用分离算法结果假装原始分轨。

**16 · 全片的一致、变化与母题**

- [ ] 16.01 哪些一直稳定：字形、色彩倾向、角色、字幕、导航、形状或运动习惯。
- [ ] 16.02 哪些随任务变：主体、空间关系、尺度、内部构成、动作过程和声音强度。
- [ ] 16.03 同一种布局讲不同内容时，内部对象与动词是否真正不同。
- [ ] 16.04 同一事件跨段继续时，保留了哪些空间与身份锚点，是否避免重复建场。
- [ ] 16.05 远距离回访如何回收先前建立的含义，和单纯重复有什么不同。
- [ ] 16.06 用同尺度总览与连续播放共同比较，代表帧不能替代动态过程。
- [ ] 16.07 角色和品牌在什么时候是主体、辅助、导航或过场资源。
- [ ] 16.08 全片是否形成有理由的密度、明暗、尺度和动静变化，哪处仍可改进。

**17 · 对照、迁移与模板化诊断**

- [ ] 17.01 按表达任务匹配片段，不只按关键词、颜色或相同三列布局匹配。
- [ ] 17.02 查文案理解、载体选择、空间、内部构成、动作、工具和全片统筹的完整链。
- [ ] 17.03 区分必要连续、合理复用与独立内容只换标签的情况。
- [ ] 17.04 重要设计提出合理替代或删除方案，写清预期损失；需要时制作实际对照。
- [ ] 17.05 对照尽量只变一个主要因素，无法保持一致的条件明确记录。
- [ ] 17.06 新内容先独立确定理解目标与具体对象，再查看可用构件，检查库是否限制选择。
- [ ] 17.07 将两分钟参考用于更长视频时，核查叙述性质、阅读量、重复累积和节奏差异。
- [ ] 17.08 真实手机页面融入整体时，检查与周围对象的关系和状态，不能只把它当照片摆件。
- [ ] 17.09 每条可复用判断附适用条件、不适用情况、原片依据及迁移验证状态。
- [ ] 17.10 实际新样段的观看结果与重建认可分开；代码可复用不等于所有组合都好看。

**18 · 根据视频类型增补的专项**

- [ ] 18.01 实拍：主体、景别、机位、角度、构图、景深、光线、环境、镜头运动与镜内动作。
- [ ] 18.02 真人表达：表演、眼神、表情、手势、呼吸、停顿、人物关系与剪辑选择。
- [ ] 18.03 录屏／操作演示：真实操作路径、等待、输入、光标、反馈、速度处理与关键界面状态。
- [ ] 18.04 图表／数据片：单位、尺度、基线、数据出处、比较关系、图例、误导风险与动态增量。
- [ ] 18.05 角色／三维动画：角色和空间连续性、动作表演、镜头、材质、光影及虚实关系。
- [ ] 18.06 混合素材：实拍、录屏、图形、资料和文字之间的职责、尺度、色彩与交接。
- [ ] 18.07 不适用项目说明理由，不为填表强行给 dots 编出机位、表演或摄影设备。
- [ ] 18.08 新参考出现现有分类未覆盖的对象或方法时，扩充类型并保留向后兼容。

**19 · 遗漏检查与工程化保存**

- [ ] 19.01 全片时间有覆盖记录：口播、无口播、停留、动作和转场区间都能找到依据。
- [ ] 19.02 每个语义步骤关联视觉段与相关元素；画面额外传达的信息也能反查出处。
- [ ] 19.03 每个可见元素组有身份、父子关系和证据；独特子部件不会被总称吞掉。
- [ ] 19.04 每个观察到的变化有动作或状态记录；循环明确范围，不能把中间过程留空。
- [ ] 19.05 每次交接有前后状态和语义理由；未知理由作为待查项保留。
- [ ] 19.06 原片、截图、局部放大、短片、数据与报告链接可访问，源时间与片段时间不混用。
- [ ] 19.07 两张主表与其他视图共用同一数据，旧编号更正有映射，修改可追溯。
- [ ] 19.08 自动检查范围、引用、缺项和冲突；工具不自动补写设计意图或宣布审美通过。
- [ ] 19.09 失败、歧义、未观察到和不适用都有实际记录，未查项不会被默认完成。
- [ ] 19.10 中断后能从待查元素／时间段恢复；重复运行复用证据，原素材与历史结论不覆盖。
- [ ] 19.11 通用流程与单条片风格分开版本化；不同语言、帧率、时长、类型和源路径可以接入。
- [ ] 19.12 完成结论回到实际原片和对照片检查；覆盖检查、研究判断与用户认可分别保存。

**单个元素的记录样式**

以下是字段要求，不是原片的已完成分析：

| 字段 | 应写到的具体程度 |
|---|---|
| 元素身份 | 元素编号、名称、所属父对象、子部件、准确文字、原片时间／帧与局部截图 |
| 可见形态 | 形状、大小与比例、色彩、线宽、圆角、纹理、阴影、字形等实际特征 |
| 空间关系 | 位置、边距、对齐、层级、内外关系、距离、与其他元素的对应 |
| 内容关系 | 关联原句／语义步骤；当前为什么需要它；是否传达额外内容 |
| 职责随时间变化 | 初现时做什么，中途是否退为参照或变成结果，退出与回访的作用 |
| 外观选择解释 | 为什么可能采取该形状、大小、位置、颜色；分别列出依据与替代解释 |
| 动作与联动 | 初态、触发、变化、终态、起止、循环、同时改变的其他部件、声音关联 |
| 反查与复用 | 删改会损失什么；哪些可保留、哪些要重做；试验状态与未解决问题 |

最终不能只得到“有卡片、有动画、节奏快”。任意指向一个独特的可见部件，都应能定位到它是什么、怎样构成、何时变化、承担什么，以及对其设计理由掌握到了什么程度。
