# 1.1.0工程示例

本目录是人工技术样本，词ID、时间和材料均为示例，非真实产品、真实声音或已认可样片。

correction.scene.json具体记录来源更正→旧判断待核→判断正文修订，并清除待核提示；next.scene.json以同一实体续接。film.json只引用两份脚本和交接理由。pause.track.json演示有限进度、停留及重新触发。

在仓库根用 `npm run dots -- check` 结合对应 words.json 检查；`npm run dots -- check-film` 读取 film.json。通过只证明结构和运行数据，不代表画面审美、声音或用户验收。
