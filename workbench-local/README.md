# 独立工作台操作

当前工作台已从旧 App 仓库提取，统一入口见 [项目 README](../README.md)。当前目录内的组件实现来自最终盘点的194项；旧 App 壳、旧内置 Agent、797项研究候选及试验副本没有迁入。

在新根目录执行 `npm start`、`npm run status`、`npm run stop`，或双击根目录启动/停止脚本。对话留在 Codex，工作台显示当前工程与实际结果。

Codex 读取和编辑仍通过本地 API/插件；命令行入口为 `node node_modules/tsx/dist/cli.mjs workbench-local/cli.ts`。修改前读取修订、选择和未保存草稿，不能覆盖手动调整。复杂场景实现放在 `scenes/`，时间绑定与参数化协议见 [SCENE_MODULES.md](SCENE_MODULES.md)。

制作循环为：粗剪确认 → 全片视觉段落与分镜确认 → 逐段实现、带原声渲染与用户确认 → 合成与整片审阅。素材缺失挂到对应段落，参数锁、撤销、素材提需、原创动画包和组件选用沿用定版功能。

历史技术记录保留在本目录各说明文件中；其中旧目录和旧 QA 证据路径仅说明原开发过程，不是独立版本的运行依赖或本次重新验收。当前迁移状态以根目录 MIGRATION.md 为准。
