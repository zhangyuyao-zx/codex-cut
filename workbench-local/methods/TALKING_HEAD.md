# 真人口播视频方法

适用于讲者出镜、真实表演和录音构成叙事基础的视频。与[共同创作方法](../CREATIVE_METHOD.md)配合使用；旁白承担讲解、画面需要独立设计时走[非真人讲解方法](FACELESS.md)。混合形式按视觉段选择主线，不规定出镜占比。

2026-11-07 升级：吸收小Lin说参考中人物、真实素材和解释图形的协作方法。按表达任务选择素材，完成必要加工，再安排人物与素材交接。这里采用的是制作方法；具体美术、人物版位和特效强度仍按本期内容设计，不能自动套成 dots，也不能固定复刻某一张参考布局。

## 从实际讲述建立基础

拍摄前将讲稿与关键画面一起考虑，识别哪些判断由讲者说、哪些事实需要材料展示、哪些过程需要操作或图解。需要的停顿、动作和补拍进入录制安排；不等拍完后才发现关键证据无法呈现。

素材到位后以真实录音和画面校正文稿，处理失败口、重复、无意义停顿、表演和切点。保留有解释作用的停顿与情绪。先形成可听、可看的带原声粗剪，再按真实时间落实画面。镜头、字幕与动画需要反过来影响采用稿时，只返修相关内容，不能静默沿用过期词锚点。

## 讲者与其他画面怎样交接

讲者可以承担观点、态度、解释与连接，真实资料承担证据，操作或图解承担可观察过程。根据此刻的理解任务决定主视觉：可以保留全幅讲者、暂让讲者缩小、切到全屏资料、放大局部，或暂不出镜。没有要求每句都看见脸，也没有要求每个论点都切全屏图。

主副角色可以在同一个段落内变化。交接时保留可追踪的上下文，例如讲者提出问题后，资料进入并取得足够阅读面积；解释结束后，视线再回到讲者。画中画不应只是为了保留人脸而挤小关键证据。

人物画面可有全幅、与素材并列、小窗陪伴、暂时退出四种职责。先判断是否需要看表情、手势和身体，再选竖窗或圆窗；不要先挑窗形再挤压表演。人物仍在说话时，原声可以连续，视觉主体不必一直是人物。

同一个对象可先是主画面，再缩到人物旁；实拍可先展示现场，再退成解释图形的背景。交接中保持对象身份、媒体播放位置和必要上下文，避免无意重播素材开头。纯图形画面也可以由前一镜头的具体对象继续推导出来。

## 主动找真实素材，并同时判断怎样加工

Codex 根据本期真实讲述主动检索已有素材与公开来源。把素材职责写进现有段落设计和素材需求，不把找素材整体转交给用户。只有用户独有的实拍、不可取得的材料或会改变表达结论的缺口，才请用户补充。

- **身份与对象：** 肖像、门面、产品、品牌标识和实际作品，帮助辨认在讲谁、哪一个对象。抽象的办公室空镜不能替代具体身份。
- **过程与规模：** 选择真正出现目标动作的片段；特写看操作，广角看规模，按解释顺序组织。题材相同不代表镜头职责相同。
- **依据与原文：** 页面、报告、真实录屏保留出处上下文；另安排重点放大、高亮、翻译或简明标注。外部材料、我们的概括和示意文字分别表达。
- **关系与类比：** 将已有真实对象放入比较、分组、流向或数量结构。实景上的透视图形是解释性叠加，不自动证明建筑产权、真实数量或实际发生的关系。
- **情绪与连接：** 表情、动作和短小情境可以承接语气。来源不明的拟人化、合成或生成片段不当现场事实使用。

选中前看实际画面和拟使用区间：主体是否易认、动作起落是否完整、裁切后是否仍成立、是否有标注空间、当前显示大小是否足够清楚、是否已有字幕、水印或强包装影响使用。记录原发布页、作者／机构、取得日期、使用区间、来源与使用范围的已知情况；需要证据的事实另行核实。可下载不等于已确认任何用途的授权。

保存原件，再在本期目录生成处理副本。主体分离需要合适的原图或实际完成的抠像，不把圆形裁切、模糊背景称为抠像。程序能够摆放透明素材，不等于已经自动完成动态人物抠像。

## 加工素材，让它承担明确的画面职责

素材来源和画面职责分别记录。同一真实图片或视频可以成为前景对象、可读依据、弱化背景或解释结构的一部分；不要只给整段贴上“实拍镜头”或“特效镜头”的标签。

| 加工 | 使用目的 | 实际检查 |
|---|---|---|
| 裁切、圆形／圆角遮罩、主体分离 | 将内容变成可识别、可摆放的对象 | 人脸、手势、商品轮廓和必要上下文没有被误切 |
| 暗化、灰化、模糊、降低对比 | 保留场景语境，把阅读权交给前景 | 主体文字可读，底层仍与当前主题有关 |
| 整页到局部、字段放大、高亮与解释文字 | 先知道出处，再读懂重点 | 放大区域确实来自该材料，不用重写的文字冒充原文 |
| 同一素材换大小和位置 | 在人物、材料、结论之间交接 | 媒体时间连续，身份不丢，移动和停留足够辨认 |
| 重复、分组、连线和数值标注 | 从具体对象进入数量或关系解释 | 重复图形的示意性质与真实统计单位分清 |
| 统一窗口、边饰或场景框架 | 容纳不同年代、画质和比例，形成段落语气 | 包装没有遮掉证据，也没有把不同来源伪装成同一现场 |

真实素材自身可能已经包含摄影、调色、广告动画、三维或合成。分析和复用时，把上游制作与本期的裁切、标注、组合分开；不要把参考里的整个成片截图当成我们新做的组件。

优先完成与本期理解任务有关的处理。清楚的现场动作可以直接承担说明，不要求每段都有复杂滤镜或运动。复杂透视、跟踪和动态抠像只在实际需要、素材条件合适且结果通过检查时使用。

## 从图形讲解中吸收的改进

- **从关系选对象。** 比较需要共同尺度，过程需要可追踪的输入、条件和结果，限制需要明确归属。配图和大字应回答理解问题，不能只重复口播名词。
- **同一事件持续推进。** 说下一句时保留仍有责任的资料、任务或图表，只追加必要变化；结束解释责任的对象再退出。不能每句重新播放同一次入场。
- **动作表达语义。** “批准后发送”可依次展示待批、获批、发送；“暂停”可让正在前进的进度停住。状态词、颜色和图标须一致；示意不冒充产品实测。
- **把注意力集中到正在讲的部分。** 旧内容可以退淡、让位，关键材料可以放大；无需让所有元素同时高亮。普通字幕、大标题、资料内原文与条件脚注分别设计。
- **让稳定画面也能继续解释。** 同一场景可经历建立、增加、变化、确认与保持；不以切镜次数、布局种类或特效数量代替节奏。
- **完整看过渡与终态。** 起中终帧用于定位，复杂动作还需播放核对。先看一个有代表性的带声片段，再完善相关段落；不额外建立六道设计审批。

这些改进补充原有真人流程，不把每段真人口播改成界面动画。讲者表演、视线、语气和停顿仍需实际观察，不能用字幕或静帧推断。

## 在现有段落设计中记录

沿用 `design.message / relationship / objects / actions / rationale`。写清主要理解任务、主副对象、真实材料来源和观看顺序；关键动作需要时补 `before / after / offsetMs / durationMs`，绑定真实词ID。主视觉可以转移，一个表达任务也可以包含多个对象和步骤。

优先设计有风险的表达交接，例如人像到全屏证据、讲述到操作、解释到结果。查看相邻段落是否连续、字幕是否遮挡材料、重点是否有足够阅读时间，再交用户审阅具体版本。采用稿、粗剪或共享代码变化后，核对受影响的声音、时间锚点与确认状态。

同时按[整片统筹](../../docs/FILM_DIRECTION.md#整片统筹的三个检查时点)检查讲者、证据与图形的整体分布。多段都让同样大小的人像配同样侧栏、按同一顺序入场时，须判断是否抹平了不同内容的责任；持续比较或同一事件的有意保持可保留，不为换画面强制讲者退出。

工程、混音、可编辑参数、素材真实性、版本保护与逐段确认沿用共同方法。修改局部只复查受影响部分；整片仍需看衔接和整体节奏。

## 制作实现入口

[真人素材制作源码 1.0.0](../../tools/talking-head-production/README.md)提供连续媒体、原图局部抽取和状态变化部件，以及工作台原生 `talking-head-media` 场景。按本期任务选择交接、证据或背景起点；需要不同布局或关系图时直接用固定源码编排。探测实际尺寸和时长后绑定当前词锚点，保留来源记录、实际画面与本期审阅。

这次采用的是方法与可运行能力，不把通用起点视为已认可的成片风格。最终质感、阅读节奏和画面取舍仍在具体样片中判断。
