# 连续画面制作与工作台交互

## 已确认边界

六步制作方法保持：粗剪 → 视觉段落 → 视觉对象 → 视觉布局 → 包装对象 → 组件与原创动画实现。
整片分镜后逐段制作、带原声审阅、用户确认具体版本、合成整片。Codex 负责创作与执行；工作台负责观看、编辑和确认。不开内置第二个 Agent，不做透明层导出，不恢复已弃用的797项研究目录。

## 从关系设计动作

每段先说明观众需要理解的关系，然后确定主副对象与变化：
- 因果：同一个对象如何被改变，结果怎样形成。
- 对比：同尺度并置，已知信息留下，焦点转移。
- 流程：对象如何传递、分裂、合并、连接或受阻。
- 实测：真实截图、录屏、数据承载证据，示意必须标明。

不是每句话都换场，也不是每段都要运动。状态连续、起态→动作→终态、阅读停留，应服从内容。动作数量不设机械配额。先理解整片，避免全片固定“人物左、文字右”。

在原有 design.actions 中记录对象、口播绑定、动作目的；必要时补起态、终态、相对偏移和明确时长。代码与动作表使用同一时间依据。旧段落不按平均时长补动画，词级时间不得凭字数推算。

## 可编辑性的交付要求

新场景交付时一并声明可选对象与常用参数：文案、颜色、位置、大小、素材、适合开放的节奏控制。用户调参数即时预览，保存后形成修订。复杂对象关系仍由 Codex 改代码；任意代码不会自动变成完整可拖动图层。
认可的布局或运动可沉淀成自有组件；先验证预览、添加、修改、保存与再打开，再标记可用，不以数量代替可用性。

## 视觉和功能验收

查看动作起点、中间、落点、相邻转场；检查字幕安全区、手机缩小后的辨认度和真实素材。无明确时长时只查口播定位，不假装知道实际落点。最终仍完整播放带原声段落，静态帧和测试通过不等于用户认可。

## 工作台设计约定

浅色玻璃导航/侧栏，内容预览保持原样；可收起资源栏与检查器，减少透明度，键盘焦点可见，减少动态效果时避免无用动画。内容和操作分层，不用大段流程说明占据视频空间。设计说明按需展开，错误与缺素材提示保留。正式运行仍是本地工作台，不变更渲染引擎。

参考研究：Overlay Studio 的组件参数定义和用途组织；Creator Pipeline 的对象连续性与动作审阅。此处独立实现，不复制其动画资产或导出系统。
