# 独立动画包

本项补齐原收尾清单中的独立文件导入、导出，不改变六步创作或逐段确认流程。核心实现、HTTP/CLI和隔离实际界面、视频输出已验证。正式服务更新状态见部署证据，其他原待办仍以收尾清单为准。

## 使用入口

组件库的「我的动画」提供「导入动画包」；选中已保存动画后提供「导出动画包」。文件扩展名为 `.cutanimation`。导入只加入动画库，不覆盖当前段落；选择目标段落、重新绑定口播、预览并应用沿用现有流程。导入后应用不自动认可样片。

Codex CLI 接口：

```sh
npx tsx workbench-local/cli.ts production/animation-templates/export '{"id":"动画ID","path":"/绝对路径/animation.cutanimation"}'
npx tsx workbench-local/cli.ts production/animation-templates/import '{"path":"/绝对路径/animation.cutanimation"}'
```

默认操作4340正式工作台。隔离验证可设置 `WORKBENCH_URL=http://127.0.0.1:4342`；仅接受本机地址。导出不覆盖现有目标文件。

## 包含内容与边界

包包含已保存的独立动画源码、模块描述、可编辑参数、锁、出现点、叠加组件信息及已捕获的静态媒体、组件媒体、补充素材，并记录文件大小和内容摘要。媒体按流复制，不把整份大视频转换成base64或读入一个内存对象。

导入先检查格式、文件清单、路径及摘要，再独占发布并登记动画库。同一份重复导入幂等；同编号不同内容明确报错，不覆盖已有源码、素材或记录。失败只清理本次新建产物。导入、列表与参数检查不执行动画源码；实际预览、渲染仍采用现有动画运行入口。

包不包含Node、React、Remotion或FFmpeg运行时，不等于安装包；目标工作台仍需要兼容的运行环境。它封装现有保存过程已经捕获的文件，不承诺自动收集任意动态网络引用或未声明的依赖。新保存动画内部补充素材已接入逐槽替换；旧固定快照保持兼容且不伪装成可替换对象，见 [素材替换](ANIMATION_MATERIAL_SLOTS.md)。
