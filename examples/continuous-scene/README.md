# 原创连续场景

本例先按表达编写镜头：单帧展开为阵列、数量汇总、抽出一帧沿流程移动、像素排队形成负担。整段由同一帧时间驱动。没有把几个现成整段模板拼起来，也没有改动 DJI 或用户工程。

`FramePipeline.tsx` 是实际实现，使用 Three.js 的空间变换和 SVG 绘制；`asset.json` 是可选的参数/对象/语义事件说明。示例不会自动入库或标记可用。实际口播需要重新编排时机，不把示例的绝对帧复制给新文稿。

安装仓库锁文件中的依赖后，在仓库根目录执行：

```sh
npx tsx examples/continuous-scene/render.ts
```

输出到忽略的 `projects/creative-proof-20261021/`：18秒静音技术视频、关键帧、改内容后的画面及依赖回执。实际试听、用户审美认可不在这个技术示例中。

用于项目时可直接维护项目场景和清单；需要复用时将此源码与 `asset.json` 合并提交到视觉库，不必为原创镜头预先入库。控件即时影响同一代码，复杂关系仍可由 Codex 改代码。此例主要用于验证创作通路，不作为所有视频的默认构图。
