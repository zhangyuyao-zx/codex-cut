# 同一视觉语言，不同画面任务

三项原创几何示例：大标题、数字与量级、对象传递与流程。它们共享实际样式控件，但采用不同的信息组织方式；不是全片必须套用的三种模板。

`assets.mjs` 导出候选资产与固定版本风格包。共同控件包含背景、文字色、强调色、字体、标题与正文字号、线宽、圆角、留白、动作时长与缓动。动画直接读取这些参数；内容控件与语义事件分开声明。

## 可选导入

启动工作台后，在仓库根目录运行：

```sh
node examples/film-direction/import.mjs
```

独立服务可设置 `WORKBENCH_URL=http://127.0.0.1:4342`。导入只登记候选资产与风格包，不选择风格、不改粗剪或制作方案、不设为 ready。新库不会自动填入这些示例。

## 制作与检查

1. 先按真实文稿设计每段的主信息、对象关系、布局与动作，再判断示例是否合适。
2. 选择风格包后，新段落只填写内容参数，样式通过 styleBindings 自动继承。显式样式和用户调整仍优先；工作台展示偏差，锁定设置不会被跟随按钮清除。
3. 绑定 begin、emphasis/count 或 step-1/2/3 到目标段落的真实词 ID，再生成带原声样片。
4. 包装页展开「全片分镜」，从已有样片提取前、中、后三张关键帧。查看并播放对照，在具体帧继续编辑。
5. 记录实际观察，再由用户逐段确认；观察记录不产生确认。设计或源样片变化后，旧记录标为历史。

2026-10-21 的工程验证在独立合成素材上完成：三种构图、共同样式继承、改变风格后的真实输出、关键帧定位与独立观察记录。没有重做 DJI，没有代替用户确认。合成素材为静音技术输入，不代表口播与动作的听觉验收。

接口和保存优先级见 [全片风格与分镜](../../docs/FILM_DIRECTION.md)。
