# 可选择导入的纸面示例

五项原创、参数化的几何示例，用于理解新资产协议。包含标题、透明圈绘、2–6步流程、2–6项关系与聚光收束。通用文案和图形可公开，不含用户视频、逐字稿、原参考画面、品牌角色、水印或音乐。

启动工作台后，**明确选择需要这些示例时**运行：

```sh
node examples/paper-style/import.mjs
```

独立测试服务使用 `WORKBENCH_URL=http://127.0.0.1:4341`。导入器只登记候选资产与风格包，既不替换剪辑或制作方案，也不设置 ready 或影片确认。已有同版本源码不同会拒绝覆盖。新库默认仍为空，不自动注入示例。

每项 `.json` 是资产描述，`codeFile` 指向同目录 `.tsx`；注册时将源码内容放入 API 的 `code` 字段。`pack.json` 固定成员版本和共享样式。`codeFile` 只属于示例文件格式，不是后端资产协议字段。

进入「视觉资产库 → 候选」查看，生成样片后可调内容、列表、颜色、布局与出现帧。实际影片由 Codex 将语义事件绑定到目标文稿，用户逐段确认。原效果检查、换内容检查及用户选定完成后才可标记可用。

仓库的 [演示视频](../../assets/readme/style-pack-demo.mp4) 来自这些原创几何的实际渲染；静音技术样片不代表已完成任何用户影片的音画验收。
