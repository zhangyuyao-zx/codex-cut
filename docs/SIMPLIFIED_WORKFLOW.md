# 工作台收敛 · v0.2.3

Codex 负责剪辑判断、六步视觉设计、动画实现、素材适配和实际检查。工作台用于看视频、调真实参数、留下修改意见和确认具体版本。

## 日常使用

1. 在 Codex 讨论制作要求，在「剪辑」看原声、按文稿剪辑并检查结果。
2. Codex 按全片内容设计视觉段落、主副视觉、布局、包装与动作；必要时讨论设计，不要求逐项填表。
3. 在「制作与审阅」修改画面参数、查看素材需求或留下意见。样片生成后自动打开这次请求的结果；主动改看其他段落或版本时不会被旧任务抢回。
4. 播放后明确确认本段，继续下一段。最后一段的「确认并合成整片」接续合成；仍可在「整片导出」重试。程序复用已确认画面，不重做全片。
5. 检查整片衔接、音画与节奏，下载视频。未确认版本、失败任务或历史样片不会被当作当前认可。

## 保留与收起

| 日常可见 | 按需展开或由 Codex 维护 |
|---|---|
| 剪辑、完整预览、逐段状态、真实画面属性 | 设计与口播说明、版本对照、手动动作定位 |
| 段落反馈、素材需求、确认和导出 | 样式映射细节、素材与语义绑定、资源入库检查 |
| 全片真实分镜总览 | Codex 的检查记录，只读显示，不要求用户填写自评表 |

「动画样片」实验入口撤下，兼容接口与已有工程继续保留。六步内容方法没有取消；它属于创作过程，不是六道页面审批。整片不再增加单独的确认表；逐段明确认可和审阅导出继续保留。

## 资源是辅助入口

右上角「资源」集中风格包、单项效果、我的动画和参考视频。资源可以给 Codex 提供材料；当前内容适合原创时直接编写场景，不先绕入库流程。旧 194 项只解析历史引用，不恢复新选型。

「我的动画」继续使用已有存档与动画包；保存后从同一入口找到。Codex 可用 `read_project` 的 `animations` 读取目录，使用 `production/animation-templates/save|preview|apply` 保存与适配。具体字段见[插件操作](../workbench-local/plugin-package/codex-cut/skills/video-workbench/references/operations.md)。手动词绑定在高级选项中；尚未适配的旧动画不会自动伪造目标内容预览。

资源范围之间切换保留本次会话的参数与绑定草稿；有草稿或正在写入时阻止离开资源工作区。应用其他资源也不会丢掉已有草稿。普通参数调整仍即时预览，不调用模型；复杂动作由 Codex 改代码。

## 权限与版本

保留 revision、源码身份、用户覆盖、锁、撤销、上一成功视频和精确渲染版本确认。Codex 的设计说明、检查记录、技术测试与渲染完成均不代替用户认可。参考提炼、候选验证和可用状态接口保持原保护，仅将技术表单收进高级选项。

此轮不重剪或重做 DJI。验证使用独立的 12 秒三段原创几何工程；其中的确认用于交互测试，不是用户对影片的审美认可。工程能力与后续真实作品质量仍分别判断。
