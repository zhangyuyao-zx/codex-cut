# Dots 1.3.0：把研究依据与物件行为接入制作

原有源码能检查状态、时间和交接记录，但作者仍可能只复用色值与外框，实际画面没有表现记录里写的变化。此次将依据准备、可组合物件和实际输出观察接入同一制作路径。参考研究工具保持独立。

## 实现

- `prepare` 校验本机参考注册表中的媒体身份与区间，输出可播放片段、适用/避用说明、固定源码和制作依据。`init` 保留为底层起点并明确提示缺少参考；已有目标拒绝覆盖。
- 固定 release 1.3.0 新增 `objects.jsx/objects.mjs` 和行为目录。材料的字段、旧提示、实体身份与位置由完整快照和确定性位姿驱动。材料迁移、局部修订和资源分配可组合，整幅构图仍由本期内容决定。
- `review-pack` 先显示实际视频和检查帧，设计与参考折叠在第二遍；观察文件初始为空。`check-review` 绑定源视频、实际播放副本、参考、取帧、规格和观察，旧证据不能证明新版本。
- `gate-render` 按场景锁定版本运行。1.3.0 将节奏证据完整性表达为 `rhythmEvidenceComplete`，`deliveryReady` 保持 false。1.0.0–1.2.0 文件未修改。
- README、导演方法、非真人方法和插件源码操作指引指向新入口；`test:dots` 汇总相关技术检查。没有自动刷新已安装插件或重启活动服务。

## 验证范围

- 32项现有状态、词时间、初始化及兼容检查通过。
- 11项原节奏检查通过。
- 9项新增检查通过：同一实体迁移与回退、实际组件正文修订/旧提示退出、非法快照/位姿拒绝、节奏与交付状态分离、准备包/拒绝覆盖、空观察拒绝、审片身份、播放副本变化失效、旧证据失效。
- 新固定源码及当前模板哈希核验通过。本机镜像与两段已认可基准也进行了独立哈希核对；私人媒体不进入此仓库。
- 本地渲染三段隔离改造：旧政策向工厂照片让位、同一交付材料试跑并补复核责任、职责与资源分配后实际改变字段。另渲染数学订正样片，复用材料部件而改变内容、布局和动作。
- 实际检查包含正常速度播放关键节点、起态/过程/终态取帧以及保留全部检测窗口的节奏说明。原已验收影片不替换。新样片属于作者完成的候选，未继承旧片用户认可；没有由代码测试推导美术已达到参考。

## 边界

审片校验只能检验文件身份与记录完整性，不能识别作者是否错误理解画面或自动判定美感。可编辑对象仍须原生 manifest 和实际参数接线。真实素材、字体、音轨、项目数据、本机配置和用户认可均留在所属项目。此次样片验证不代替未来整片的相邻关系、节奏和带声审阅。
