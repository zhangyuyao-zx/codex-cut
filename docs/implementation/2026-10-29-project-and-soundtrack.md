# v0.3.1 · 独立工程与完整混音

本次补齐文稿／素材交接之后的两处制作接口：选择独立项目时识别实际目录；加入音乐或音效后，让同一完整音轨进入预览、段落与整片。创作方法、用户覆盖／锁及逐段具体版本认可继续沿用。未制作或确认用户真实内容。

## 工程接入

- `select-project.mjs` 在服务停止后选择目录，空目录要求稳定内容编号和名称，非空旧工程保留身份；不导入、不启动、不覆盖旧目录。
- `projects/active-project.json` 仅保存本机选择，不进 Git。环境覆盖优先，必须绝对路径；选择器发现不同覆盖会拒绝。源码根及上级目录禁止作为工程，服务初始化前拒绝未知非空目录与编号冲突。
- Launcher 与选择器共享仓库端口锁，等待启动期间选择变化会拒绝旧目标。日志在 `projects/.launcher-runtime/<port>/server.log`。
- health、插件 summary/status 返回实际 projectDir 和可用的 contentId。插件每次写入前核对源码根与工程目录，提交时带目标路径；服务端核对该标记。浏览器原有 token 接口保持兼容，不强制所有直接客户端都加路径标记。
- 无选择记录时保持默认目录；旧服务没有 projectDir 字段，须先用旧版本正常停止。原始素材与旧工程没有迁移或修改。

## 声音链

`production/soundtrack` 接收完整音轨的本地路径（null 为明确清除），同时要求制作 revision 和 expectedCutRevision。已有工具负责混音，工作台只接收一条从全片零点对齐、等长（容差一帧）、包含应保留口播的音轨；没有新增多轨调音台。

导入后保存独立只读副本，核对可解码音频、时长、SHA-256 和粗剪版本。原生预览覆盖源片音轨；正式段落按全片帧位置裁切；合成以当前完整音轨保持连续。母带身份和绑定次数纳入段落 key，更换／清除不会复活旧认可。缺失、改写或粗剪过期会阻止输出，不静默退回原声。命名备份现有 production 捕获范围包含声音文件。

声音 GET 和上下文读取使用已有内容摘要缓存；渲染复制仍实读校验。声音实现文件纳入渲染代码身份。没有绑定的新旧工程继续采用原声路径；本次源码升级仍可能使旧渲染成为历史版本，原确认账本保留。
