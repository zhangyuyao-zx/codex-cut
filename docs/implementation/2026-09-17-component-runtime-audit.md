# 194 项组件：渲染与表单检查

本轮沿用 App 最终盘点的 194 项，没有增加研究目录组件，也没有修改正式影片。此记录是功能证据，不是全库审美认可或全库视频验收。

## 修复

- 可选参数没有声明默认值时保持未设置，避免强行写入无效空字符串/空数组。已确认影响 22 个逐项动画的 `cueFrames`、仪表盘的 `thresholds`、渐变文字的 `colors`；全库初始化检查还发现主题转场的可选 `accentColor` 同类问题。
- 可选列表提供显式自定义开关；关闭时移除参数，恢复组件默认行为。`cueFrames` 提供数值条目类型，避免显示成无法改成数组的文字输入框。
- 渐变文字只有一种颜色时复制色标，显示为单色；此前校验允许单色，但 CSS 渐变无效会使透明文字消失。
- 更新共享组件的运行时源码标识，保持版本识别与修改一致。

## 实际证据

使用 `AppLibraryComponent`（与工作台预览相同的适配器）在本机 Chromium 中渲染；每项使用经校验的示例参数、按素材槽数量绑定示例图片，在 0 / 45 / 120 帧输出 PNG。

- 194 项、582 张 PNG 全部生成，无渲染异常。主代理查看了覆盖 194 项的第 45 帧图版。
- 全库表单初始值检查：仅填写必需内容，194 项均通过参数与素材需求校验。该检查避免用完整示例参数掩盖初始表单缺陷。
- 实际浏览器验证渐变文字：填写文字后可预览且添加按钮可用；开启颜色列表、增加条目、填写颜色、关闭自定义均可操作。测试草稿已放弃，未添加到正式段落。
- 单色文字另做了真实 5 秒 H.264 导出，960×540、150 帧；已查看修复后的实际静帧。
- 工作台参数/素材测试 9 项通过；共享组件运行时测试 5 项通过；工作台 TypeScript 检查通过。

- 尚未逐项完成 194 个组件的 UI 添加、视频素材、多种时长、完整动画及段落导出测试。本轮三帧渲染只证明这些固定输入可渲染。
