# 真人与真实素材制作升级 · 2026-11-07

真人讲解需要让讲者、现场、操作、页面证据和解释图形承担不同职责。已有 `talking-head-story` 为特定旧片编排，不能直接承担通用的素材加工与交接。本次保留旧场景，新增 `talking-head-media` 原生场景和固定版本制作源码，并更新真人方法。

## 改动

- [真人制作方法](../../workbench-local/methods/TALKING_HEAD.md)：主动选材、原始来源与画面职责、加工副本、人物交接、真实原文与概括的区分、上游效果与本期加工的区分。美术独立于 dots。
- [制作源码 1.0.0](../../tools/talking-head-production/README.md)：帧驱动的媒体视图、稳定的源时间、原图区域等比抽取、焦点裁切、圆角、透明度、亮度、饱和度与模糊。媒体层静音，原声继续由工作台声音轨承担。
- 原生 `talking-head-media`：交接、证据、背景三种制作起点；人物全幅、并列、小窗或退出；人物、材料、重点、标题和出处接受既有画布覆盖。构图需要不同表达时，直接用源码部件创作。
- 只读 `probe` 命令：从实际文件获取显示尺寸、时长、composition FPS 下的可用帧数、音轨状态与 SHA-256。主片和素材时长不足、缺素材、歧义锚点、越界和重叠动作都会明确失败，不暗中补假素材或循环。

未改变工程格式、素材上传接口、声音轨或旧真人模块；未新增运行依赖。原生模块静态导入版本目录，沿用递归 sourceHash。具体页面、口播、录屏、音轨与测试输出不进入公共 Git。

在独立验证目录用既有真人粗剪、实际工作台录屏和截图渲染：

- 主样片 577 帧，30 fps，1280×720，视频画面约 19.23 秒，包含原口播音轨；三个起点依次出现。
- 替换素材样片 243 帧，30 fps，1280×720，约 8.1 秒画面，换成不同比例的真实图片并指定不同源区域。
- 实际渲染的自制帧号素材，在场景第 76、130 帧分别显示源第 36、90 帧，与源裁切 12 帧、入场 52 帧的计算一致。版位变化没有重启源播放。
- 实际渲染画布覆盖，确认标题移位／缩放、人物移位／缩放及出处隐藏生效。
- 检查代表状态与交接帧，修正一次证据标题裁切及资料叠在返回人物面前的问题；浏览器检查播放、定点跳转和媒体加载无错误。
- 对照升级前记录，活动工程 50 份 JSON 与旧真人场景两个文件字节保持不变。未向活动工程调用渲染或写入接口。

画面检查和播放能力检查不等于完整人工听审或用户审美认可。本次是制作能力的技术交付；样片素材、节奏和美术尚未作为正式作品定稿。复杂动态抠像、透视跟踪、多对象图解等仍按本期需要另做并验证。
