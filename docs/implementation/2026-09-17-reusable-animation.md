# 原创动画保存与复用

## 范围

延续 Codex 编写动画、工作台编辑与审阅的方式。复用已有画面实现时，保存代码版本、参数控制和口播出现点，再为目标段落重新绑定口播；不把原视频的绝对时间和素材路径直接搬过去。

用户入口：包装页右侧「保存为我的动画」→ 组件库「我的动画」→ 选择目标段落 → 按顺序绑定出现点 → 带原声预览 → 应用到当前段落 → 编辑文字与样式 → 生成并审阅样片。

保存动画与确认成片是两件事；保存不产生用户审美认可。应用仍使用现有工程修订与撤销机制，不新增工程格式。

## 实现边界

- 模块代码及本地依赖打包为独立版本，使用现有场景模块入口供预览和导出共同加载；React/Remotion仍由现有运行环境提供。
- 旧场景内部的段落ID与口播词ID通过适配入口保持，新段落仅提供新的帧位置。需要动态文本的字段仍须由动画作者声明成参数。
- 保存已解析参数和锁；应用时目标段落已有的兼容用户调整优先。参数不兼容则说明原因，不能丢掉修改继续。
- 原创模块之外额外叠加的组件现已随动画保存，保留独立参数和素材绑定；出现/结束加入统一口播对应表。已提供的补充素材复制为模块素材快照，保持原素材身份供动画代码引用。
- 不复制旧口播、反馈、认可记录。目标旧设计笔记移除，避免把原设计当成新动画已验证的说明。
- 任意硬编码内容、任意未声明的词引用和外部运行时资产不能保证自动适配；应检查实际预览后使用。

## Codex入口

沿用 `workbench-local/cli.ts`：

```sh
npx tsx workbench-local/cli.ts production/animation-templates
npx tsx workbench-local/cli.ts production/animation-templates/save '{"sceneId":"段落ID","name":"动画名称"}'
npx tsx workbench-local/cli.ts production/animation-templates/preview '{"id":"保存动画ID","sceneId":"目标段落ID","bindings":["目标词ID"]}'
npx tsx workbench-local/cli.ts production/animation-templates/apply '{"id":"保存动画ID","sceneId":"目标段落ID","bindings":["目标词ID"]}'
```

每个出现点需要一个有序且不重复的目标词ID。读取当前工程获取真实词ID；不要按旧绝对时间猜测。CLI自动带当前修订；可显式提供之前读取的 `expectedRevision` 防止覆盖并发修改。保存和复用不是审美批准，之后仍按逐段样片审阅流程处理。
