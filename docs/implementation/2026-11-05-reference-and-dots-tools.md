2026-11-05。此前，通用参考研究与 dots 制作方法的可执行工具尚未进入公共仓库。此版将两者分别整理为可运行的源码工具，接入 README、两条制作主线的共同方法及插件使用入口。

研究输入、研究结论与制作实现分开。制作工具只准备源码和检查计划，不创建或切换工作台工程，不改变旧作品的固定版本，不设置视觉库 ready 或用户认可。原生素材、时间、参数覆盖、锁、混音与审阅链路继续使用。

公共资料不包含私人原片、产品页面、研究转写、基准视频、音乐、字体文件、工程及本机配置。合成示例不声称反映真实视频观察。dots 固定运行代码沿用已整理的源码版本；公共发布的索引、说明和 manifest 元数据独立整理，不带私人基准链接。

## 使用边界

- 参考研究仍由研究者实际观看、听辨和解释；自动工具检查记录结构，不能证明观察真实，也不自动完成转写和视频理解。
- 当前研究逐帧导航支持 CFR，VFR 拒绝并要求另建源时间映射。未绑定原片时可浏览图像与记录，播放入口禁用。
- dots 的 `inspectionGaps` 检查计划中未交代的区间，不检测成片像素是否静止；相似布局提示需要人工复看，不采用布局配额。
- 公共源码套件不等于原生视觉库风格包。已有作品继续使用自己的源码副本与版本；跨机器字体和渲染运行时需要另行配置。
- 本次发布更新 GitHub 源码及仓库内插件包，不自动刷新已安装的插件缓存或重启活动服务。
