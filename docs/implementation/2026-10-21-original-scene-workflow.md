# 原创场景与风格适配 · v0.2.1

这次修正针对参考提炼升级中暴露的模板重复、风格覆盖不透明和原创依赖受限。工作台继续负责真实素材、时间、用户参数、版本和逐段确认；创作可直接编写项目场景，合适时复用，完成作品后再提炼有价值的资产。

## 实现

- 资产与原生场景清单可声明固定版本的浏览器动画依赖。首批支持 Three.js、Fiber 和 Remotion Three；资产保存不会自动安装。入口、本地辅助源码和依赖版本参与检查及结果身份；预览与正式渲染使用精确一致的包解析。Three 场景按官方建议使用 ANGLE，普通无动画依赖的2D场景保持原后端。
- 保存场景动画保留依赖声明、原生 styleBindings、用户覆盖和锁。恢复到缺包或版本不符的环境会明确拒绝使用。嵌套视觉 OBJECT 仍依赖目标视觉库，当前不声称完整跨机器独立分发。
- 任何主动声明 styleBindings 的项目原创场景或新资产均可使用包 token，不必属于固定模板集合。原有显式参数、用户覆盖与锁优先；成员专用预设只对固定成员生效。
- 风格预览、制作页与插件读取提供逐段覆盖：已映射、部分映射、尚未适配、未实现和冲突。没有可自动映射项也可先设置创作方向。字体、材质、构图、动作与声音由 Codex 根据 brief 落实，不能把参数映射说成整片设计已完成。
- 制作 Skill 允许直接原创，把参考使用和资产入库分开。六步保留为内容判断，可在一份方案中迭代；不要求先入库、先做通用组件或机械分成六轮审批。
